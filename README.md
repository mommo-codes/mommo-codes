# Hey, I'm Mommo 👋

I'm Muhammad Saad, a software engineer in Stockholm and an M.Sc. Computer Science student at Uppsala University. I work at Wolt Sweden as a Process & Automation Associate, where I design and build internal tools for catalog operations across markets. I also build websites at Kabir Studios.

My thesis, written in collaboration with Wolt, explores how ML and statistical methods can detect data quality violations in retail datasets.

Some things I've built:

- [barkod](https://github.com/mommo-codes/barkod): GTIN parsing, canonicalisation and match keys, callable from Rust, Python and TypeScript
- [mangel](https://github.com/mommo-codes/mangel): turns irregular product data into regular product data
- [matchr](https://github.com/mommo-codes/matchr): fast fuzzy string matching in Rust, with Python bindings

Outside of work, I train regularly and I'm currently working toward completing a Svensk Klassiker.
